# Tanzlexikon

Eine Android-App als Gedächtnisstütze für Tanzfiguren: Figuren aus der Tanzschule nach Tanz und Kategorie sortiert sammeln, mit eigenen Videos, Bildern, YouTube-Links und Notizen, damit sie auch ohne regelmäßiges Üben nicht in Vergessenheit geraten.

<!-- Screenshot folgt -->

## Funktionen

- Tänze, Kategorien und Figuren anlegen, sortieren und durchsuchen
- Videos und Bilder aus der Galerie verknüpfen oder direkt aufnehmen
- Papierkorb zum Wiederherstellen gelöschter Figuren
- Alles exportieren und wieder importieren (Sicherung)
- Einzelne Figuren als `.tanzfigur`-Datei an andere schicken
- Hinweis auf neue Versionen

## Installation

1. Die neueste `app-release.apk` unter [Releases](https://github.com/Katzfuss11/tanzlexikon/releases) auf das Handy laden.
2. Die Datei antippen, „Unbekannte Apps installieren“ erlauben und installieren.

Voraussetzung: Android 8 oder neuer.
